# Contributing

Thanks for improving this list! Contributions are welcome.

## How to Contribute

1. Fork this repo and create a branch, e.g. `add/project-name`.
2. Add one row to the matching table in [README.md](README.md).
3. Open a Pull Request and briefly explain why the entry deserves inclusion.

## Inclusion Criteria

- AI-related and genuinely useful — a project, tool, or product.
- Open-source projects need real substance (no empty repos, pure demos, or unchanged forks); hosted products need some public recognition.
- Use the canonical official link — no affiliate or tracking parameters.
- Not a duplicate of an existing entry.

## Entry Format

For an open-source GitHub project:

```markdown
| [Project Name](https://github.com/owner/repo) | [![stars](https://img.shields.io/github/stars/owner/repo?style=flat-square)](https://github.com/owner/repo/stargazers) | Short, objective description. |
```

For a hosted product or website:

```markdown
| [Product Name](https://example.com) | <img src="https://www.google.com/s2/favicons?domain=example.com&sz=32" width="16" height="16" alt="favicon"> | Short, objective description. |
```

- Keep descriptions under ~150 characters — say what it is/does, without subjective adjectives.
- Stars and favicons are generated automatically by badge services — never enter them manually.

## Other Notes

- Dead-link fixes and wording improvements are always welcome, no special format needed.
- One project per pull request — it keeps reviews fast.
- By participating, you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
